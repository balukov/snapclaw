# Issue Tracker

Use Linear MCP, team Developer (DEV).
Every issue carries `snapclaw` and one of Bug, Feature, Improvement.

Search existing issues before creating a new one.
Use the mappings in `triage-labels.md`; preserve unrelated labels.
Resolve team, label, and status IDs through MCP.

Record dependencies using native "blocked by" relations.
Keep acceptance criteria and validation evidence on the issue.

For wayfinding, use a parent issue for the map and child issues
for implementation steps. The next frontier consists of unfinished
ready-for-agent children whose blockers are resolved.

If Linear is unavailable, report the blocker and retain local drafts.
