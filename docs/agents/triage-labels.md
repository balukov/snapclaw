# Triage Labels

| Role / Linear label | Meaning |
| --- | --- |
| needs-triage | Needs maintainer evaluation |
| needs-info | Waiting for more information |
| ready-for-agent | Specified work an agent can complete alone |
| ready-for-human | Needs owner access, device playtesting, or judgment |
| wontfix | Will not be actioned |

Apply these alongside the repository and issue-type labels.
Preserve unrelated labels when updating issues.
